# AI Team Memory

This directory preserves durable, reviewable context for My Scoope's business
areas and cross-area initiatives.

## Structure

- `areas/`: one current memory file per durable business area;
- `projects/`: one file per active or materially reusable initiative;
- `decisions/`: accepted decisions about the AI team and its operating model;
- `../templates/`: formats for new area, project, and decision records.

## What belongs here

- objectives, operating constraints, recurring workflows, and open questions;
- links to authoritative product, financial, commercial, or operational evidence;
- role ownership and handoffs;
- compact outcomes that will matter in a future conversation;
- dated assumptions and their validation status.

## What does not belong here

- copied product specifications or architecture rules;
- raw logs, transcripts, customer records, health information, credentials, or secrets;
- unverified figures presented as facts;
- recommendations recorded as accepted decisions before Felipe approves them;
- transient task notes that will not help future work.

## Update rule

Memory updates must be attributable, dated, and additive when correcting an earlier
claim. Link to the evidence and mark assumptions explicitly. External systems remain
their own sources of truth; this memory records navigation and durable conclusions.

Roles read the smallest relevant memory file. They write here only when the current
request or an approved automation authorizes recording the result.
