# Team Capabilities Memory

Status: active
Last reviewed: 2026-10-24
Owner role: `ai-team-capability-steward`

## Objective

Maintain a small, sufficient, trustworthy set of AI roles and shared skills that
grows with real company needs.

## Current operating model

- Felipe retains final authority and may work directly with any role.
- The Capability Steward designs and reviews the portfolio but does not supervise
  every task.
- Coordinators delegate to specialists only when separate expertise or independent
  evidence improves the result.
- New roles begin in pilot unless their workflow and evidence are already proven.
- Repeatable procedures used by several roles are registered as shared workflow
  skills rather than positions in the organigram.

## Current priorities

1. Evaluate the newly created pilot roles through real conversations.
2. Configure the provisional accounting workflow before unattended operation.
3. Record concrete failures, overlaps, and missing capabilities as evaluation
   evidence rather than adding speculative rules.
4. Pilot `mobile-simulator-review` on real visual changes and verify that its
   evidence packet prevents stale checkout, Metro, native-build, and API confusion.
5. Pilot `fresh-task-checkout` on new technical tasks and verify that each begins
   from a fetched `origin/staging` commit without disturbing existing worktrees.
