# Finance Memory

Status: active
Last reviewed: 2026-10-23

## Objective

Give Felipe traceable financial information, decision support, and financing
preparation while preserving human control over accounting policy, commitments,
payments, filings, and external representations.

## Roles

- `accounting-intake-recordkeeping-agent`: provisional operator for source documents.
- `financial-planning-advisor`: pilot advisor for cash, budget, runway, and scenarios.
- `funding-advisor`: pilot advisor for financing alternatives and preparation.

## Configuration gaps

- authoritative bookkeeping register and chart of accounts;
- approved Drive structure and mailbox intake;
- planning model, base currency, reporting cadence, and scenario assumptions;
- financing objectives, constraints, readiness evidence, and target instruments.

Do not store account credentials, banking details, tax identifiers, raw invoices,
or investor personal data in this repository memory.
