# Manuals

Status: current
Last updated: 2026-07-08

This folder is reserved for official human-facing manuals about how to use and operate My Scoope.

It is different from `manual_docs/`, which contains personal notes and must remain outside the official documentation context.

## Rules

- Add manuals here only when they describe stable usage or operational behavior.
- Do not use this folder for private notes, temporary ideas or implementation scratchpads.
- If a manual creates or changes a durable product rule, reflect that rule in `docs/00_current/` or `docs/20_decisions/`.
